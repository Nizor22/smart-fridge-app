- [ ] Dispatch Explorers / Spec Miners to map all source files under `src/`, `schema.sql`, `package.json`, `app.json`, and current architecture.
- [ ] Publish `PROJECT.md` with complete Feature Inventory and file mapping.

- [ ] Dispatch **Principal React Native Engineer** (Explorer/Worker) to analyze file-by-file all `.ts`/`.tsx` files under `src/` for bugs, memory leaks, race conditions, unhandled promises, stale closures, missing error boundaries, loading/offline states, and `useMemo`/`useCallback` optimizations with before/after code.
